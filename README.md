# 🌐 Enterprise Network Simulation using Cisco Packet Tracer

A complete enterprise network simulation built in **Cisco Packet Tracer** implementing dynamic routing protocols, VLSM subnetting, NAT, ACLs, DHCP, Email, FTP, and Web services.

Developed as the semester project for the **Computer Networks** course at **FAST – National University of Computer and Emerging Sciences (FAST-NUCES)**.

---

## ✨ Features

### 🌍 Enterprise Network Design

- Multi-router enterprise topology
- Multiple LANs and WAN links
- Hierarchical network design
- Full end-to-end connectivity

### 📡 Dynamic Routing

Implemented multiple routing protocols:

- OSPF
- EIGRP
- RIP Version 2
- Route Redistribution between routing domains

### 🌐 IP Addressing

- Variable Length Subnet Masking (VLSM)
- Efficient IP allocation
- /30 point-to-point links
- Optimized subnet utilization

### 📥 DHCP

- Centralized DHCP Server
- Automatic IP assignment
- DHCP Relay (IP Helper Address)
- Multiple DHCP pools

### 🔄 Network Address Translation (NAT)

- Static/Dynamic NAT
- PAT (Overload)
- Public-to-private IP translation

### 🔒 Network Security

Access Control Lists (ACLs) used to:

- Restrict HTTP access
- Control network communication
- Protect internal resources
- Enforce security policies

### 📧 Network Services

Configured services include:

- Web Server
- FTP Server
- Email Server (SMTP/POP3)
- DHCP Server

## 🚀 How to Run

### Requirements

- Cisco Packet Tracer (Instructor or Student Version)

### Steps

1. Clone the repository

```bash
git clone https://github.com/mueedmak/computer-networks-packet-tracer.git
```

2. Open the `.pkt` file using Cisco Packet Tracer.

3. Wait for the topology to initialize.

4. Use **Simulation Mode** or **Realtime Mode** to test the network.

5. Verify:

- Routing tables
- DHCP assignment
- NAT translations
- ACL restrictions
- Email communication
- FTP access
- Web server connectivity
